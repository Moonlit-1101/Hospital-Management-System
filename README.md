# 医院管理系统
> 基于若依框架开发的医院管理系统

## 目的
本系统主要面向医院内部的护士和医生群体，开发护士端和医生端两个功能模块。护士端实现病人信息新增、护理日志记录以及药方管理与库存管理的增删改查功能；医生端完成病人诊断，并判断病人是否需要住院。通过这些功能的实现，提高医院工作效率，减少人为操作失误，保障医疗信息的准确性和及时性。


## 部署须知
- 后端文件夹名 hospital 
需要安装mysql8.0及以上版本，redis5.0
- 前端文件夹名 web
- 数据库文件 vote.sql
需要导入mysql（可借助navicat等工具，15or17）
